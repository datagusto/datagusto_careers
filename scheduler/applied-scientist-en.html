About Product

Design the Self-Improving Feedback Loop for Agent Inference

Our scheduler decides where and when AI agent workloads run on GPUs so that jobs finish on deadline at lowest cost. That only works if we can estimate each job's true deadline and acceptable quality—even when explicit ground-truth labels are never provided by users.

For Engineers

It is the workload side, not the GPU side, that knows which jobs are not urgent.

Agent tasks do not come with explicit ground truth for "how long was actually acceptable?" or "did a cheaper model degrade quality?". The core challenge is extracting implicit feedback signals from operational traces and designing unbiased offline and online evaluation.

The Core Frontier

Observational bias is everywhere: you only observe latency and quality for the GPU and model you actually chose. Counterfactual outcomes ("what if we ran it on an older GPU?") remain hidden unless purposefully explored through shadow execution and rigorous off-policy evaluation.

Your Direct Impact

You formulate proxy metrics (time until human consumption, rework, reruns) and build quantile regression / conformal prediction baselines that the Founding Engineer directly implements into the production pipeline.
